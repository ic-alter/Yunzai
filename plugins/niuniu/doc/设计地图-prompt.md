任务一、地图设计 
请你仿照上面的结构，生成一些新的地点以及地点之间的通路 
说明 
1. 这里的数据结构是当前地点:[从该地点可以到达的其他地点]。例如新手村: ["酒馆","冒险家协会","新手村郊外"],，意思就是新手村可以到达酒馆、冒险家协会、新手村郊外 
2. 地点名称在代码中会作为key，所以必须保证地点名称不可以重复。例如已经有一个地点叫新手村，那么新创建的地点就不可以叫新手村，否则key会重复 
3. 地点之间可以是双向连接（例如A可达B，B可达A），也可以是单向连接（例如A可达B，但B不可达A）。因为只是一个游戏，所以无需考虑现实中的空间限制。但为了游戏性保证，每个地点必须有至少一个可达地点，而且也不可以某几个地点之间互相可达但与其他任何地点都不可达。 
4. “奇怪的传送门”是特殊地点，你会发现“潮湿温暖的洞内”“潮湿温暖的洞穴深处”“奇怪的传送门”这几个地点是单向的，进入之后就无法出去，这看起来和第三条相违背，因为这是一些特殊的游戏机制，你保留原样即可。同时，你创建的新地点以及通路不可以有通往“潮湿温暖的洞内”“潮湿温暖的洞穴深处”“奇怪的传送门”这三个地点的。
5. 你除了增加新的地点之外，也需要给出原有地点通往新地点的通路。单独给出原来的哪些地点需要修改，如何修改 


任务二、事件设计 对于每个地点，你需要根据地点的特性，设计一到两个符合这个地点的“事件”。 你不需要给出代码，只需要给出用自然语言描述的事件创意即可 
数值： 
以下数值，既可以作为事件分支的条件，也可以作为事件的结果改变的数值： 
1. 金币：游戏内的货币。事件可获得或消耗的金币一般是以10000-200000的数量级。 
2. 金叶：游戏内的一种神奇的液体，单位ml，事件可获得或消耗的一般是100-2000的数量级 
3. 健康：孩子的身体健康。如果事件内发生了受伤或中毒一类，健康一般会降低。如果有补充体力之类的可以增加。其数值在1-100之间。（一个玩家可能拥有许多孩子，事件的处理对象是孩子） 
4. 心情：孩子的心情。 
5. 天赋 5.1 智力 5.2 体能： 5.3 外貌 5.4 情商 
6. 牛牛：游戏内每个玩家唯一拥有的一个武器。参数包括长度和半径。需要注意，长度和半径变化只能百分比变化，不能固定值变化。例如长度和半径增加/降低20%是允许的，但是长度/半径增加20cm这种是不可以的。而且牛牛只能作为事件影响的结果，不可以作为准入条件或者分支触发条件。 6.1 长度 6.2 半径 
此外，也有一些因素，在事件内不可以更改，但可以作为准入条件或分支触发条件 1. 孩子性别：只有男|女 2.孩子的姓名 3. 牛牛的硬度等级。
7. 道具：

 用自然语言描述的事件需要包含以下要素： 
 - 事件名称 
 - 前置提示语句：用有趣的语言描述这个事件 
 - 准入条件：进入这个事件所需要的条件。注意，准入条件只允许孩子的健康、心情、天赋作为准入条件。其他的值（如金币、金叶、牛牛）不可以作为准入条件 
 - 分支：根据不同的情况进入不同的分支，分支条件可能是各项数值、随机概率，或者各项数值与随机概率的结合等 
 每个分支包含下面两个要素 
 - 数值变化规则：数值会受到怎样的影响 
 - 事件结束语句：用自然语言描述这个事件产生的结果 
 
 一个示例： 事件名称：吃小木屋 前置提示语句：发现小木屋的墙壁和屋顶和窗户竟然都是用糖果和巧克力搭建的！看起来很好吃的样子。 准入条件：健康>50 分支1：外貌>80 数值变化规则：心情+15，健康-20，体能-30，智力和情商+15 事件结束语句：{孩子name}正在吃小屋的时候，被房子拥有者的巫婆发现了，但巫婆看着{孩子name}长得这么可爱，心生怜爱，于是宠溺地说这个小屋都给{孩子name}吃；心情、智力和情商中幅度增加。但{孩子name}因为吃掉了一整个小屋，胃袋变成超大胃袋，健康和体能大幅度降低。 分支2：外貌小于80但体能>80 数值变化规则：心情+5，体能-5 事件结束语句：{孩子name}正在吃小屋的时候，被房子拥有者的巫婆发现了，还好体能基础好，虽然胃袋已经满了但仍然成功溜走。心情略微增加，体能略微减少。 分支3：default 数值变化规则：情商+5，金币减少70000 事件结束语句：{孩子name}正在吃小屋的时候，被房子拥有者的巫婆发现了，苦苦哀求下巫婆仍要求赔偿损失，只好赔偿她70000金币。 
 
 对于事件的生成，有以下要求： 
 1. 事件的数值增减需要用一些有趣的事件文案来解释，尽量符合逻辑。可以有好分支和坏分支，也可以有好事件和坏事件。事件文案主要风格是搞笑的，有些事件可以是包含一点微恐怖。 
 2. 健康、心情、天赋的取值都是1-100。你可以进行整数的增减。代码中已经有边界值处理所以你在事件中不需要处理。这些值不要百分比的增减 
 3. 金币和金叶可以增加或消耗。金币一般以10000-200000为量级，金叶一般以100-2000ml为量级。如果你的事件内容是获得了大量资源或者立了大功，那获取量可以酌情增加，但无论如何不要超过2000000金币或20000ml金叶。你可以进行整数的增减，也允许较小比例的百分比增加（10%以内，例如金币增加10%，或者金叶减少30%） 
 4.对于牛牛的长度和半径，只允许百分比增减，不允许数值增减。百分比减少不得超过50%（例如最坏的事件惩罚也只能是牛牛长度和半径减少50%）。百分比增加不得超过100%。 
 5. 允许数值之间的转化。例如智力越高获得的金币越多，或者说牛牛硬度越高事件进入成功分支的概率越大。但牛牛的长度和半径不可以作为数值转化的来源。
 6. 只生成事件的文案即可，不需要给出代码。你生成的每个地点，都可以包含1-2个与地点风格相符的事件。
 7. 对于事件的分支，你需要保证事件必定进入其中一个分支。例如保证所有分支包括了所有情况，或者互为互斥事件，或者设置兜底分支
